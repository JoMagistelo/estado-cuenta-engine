# Visión del Proyecto

## Nombre

Estado Cuenta Engine

## Objetivo

Construir un motor de extracción y normalización de estados de cuenta bancarios que permita convertir documentos PDF en información estructurada y exportable a Excel.

## Alcance inicial

- Banco BBVA
- PDF digital
- Un estado de cuenta mensual
- Exportación a Excel

## Futuras etapas

- OCR
- Más bancos
- Base de datos
- Procesamiento masivo
- API
- Dashboard
